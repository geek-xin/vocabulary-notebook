# 设计文档：首页查询输入 + 卡片三行布局

- 日期：2026-09-18
- 状态：已确认，待实现
- 作者：geek-xin

## 一、背景

词汇本首页（`index.html` 的 `#homeView`）目前只有「导入词汇本」一个操作入口，词汇本数量变多后
只能靠肉眼在卡片网格里找，缺少检索能力。

同时，`.book-card` 目前是两行结构：第一行标题，第二行把「词数 + 时间 + 分享/删除按钮」挤在
同一个 `.book-meta` flex 行里（按钮靠 `margin-left: auto` 推到最右）。信息与操作混排，卡片内
容一多就显得拥挤。

本次改动解决这两点，不涉及数据结构和存储逻辑。

## 二、范围

| 项 | 结论 |
| --- | --- |
| 查询范围 | 词汇本**标题**，或词条**单词**、**中文释义**命中 |
| 查询位置 | 首页导入按钮行与卡片网格之间 |
| 数据影响 | 无。纯前端过滤，不新增存储键、不改动已存词汇本 |
| 卡片结构 | 由两行改为三行：标题 / 数量+时间 / 按钮 |
| 移动端时间标签 | 取消原本的 `display: none`，第二行正常显示数量与时间 |

## 三、交付物一：首页查询输入

### 结构

在 `.home-actions` 与 `.book-grid` 之间新增一行 `.home-search`，包含放大镜图标、
`<input type="search">` 与一个清除「×」按钮。输入框放在 `#bookGrid` **之外**，因此
`renderHome()` 重绘网格时不会丢失输入焦点与光标位置。

`body.home-mode #homeView .home-search` 需要加入 `flex: 0 0 auto` 规则组，保证首页依旧是
「标题 / 导入 / 查询」固定、仅卡片区滚动。

### 匹配规则

大小写不敏感、去除首尾空格。一个词汇本满足下列任一条件即显示：

1. `book.title` 包含关键词；
2. `book.words` 中存在词条，其 `word` 或 `meaningCn` 包含关键词。

空查询视为不过滤，显示全部词汇本。

### 交互

| 场景 | 行为 |
| --- | --- |
| 输入 | `input` 事件实时过滤，立即重绘网格 |
| 有查询 | 显示「×」按钮，点击清空 |
| 键盘 | 输入框内按 `Esc` 清空查询 |
| 计数徽标 | 过滤时显示「匹配 M / 共 N 个词汇本」，未过滤时为「共 N 个词汇本」 |
| 卡片提示 | 命中单词的卡片在第二行追加「命中 K 词」标签 |
| 无结果 | 网格内显示空态：提示语 + 「清除查询」按钮；无词汇本时的原有空态保持不变 |

### 视觉

沿用现有玻璃拟态风格：`rgba(255, 255, 255, 0.08)` 背景、1px 半透明描边、12px 圆角，
聚焦时边框转为主题黄色 `rgba(255, 217, 102, 0.42)`，与卡片 hover 态一致。

## 四、交付物二：卡片三行布局

### 结构

| 行 | 元素 | 内容 |
| --- | --- | --- |
| 1 | `.book-title` | 标题，最多 2 行截断（不变） |
| 2 | `.book-meta` | 词数 + 创建时间（+ 命中时的「命中 K 词」标签） |
| 3 | `.book-actions` | 分享、删除按钮，靠左对齐 |

### 样式调整

- `.book-card` **不设 `min-height`**，高度完全由内容决定；`.book-grid { align-items: start }`
  避免卡片互相拉伸。这样按钮下方不会留大片空白。同一行里单行标题与两行标题的卡片高度会不同，
  这是「不预留空行」的必然代价 —— 二者不可兼得。
- `.book-card { gap: 10px }`：三行之间留出呼吸感，不要挤在一起。
- `.book-meta` **去掉 `margin-top: auto`**：原本它把第二行推到卡片底部，标题与数量/时间之间
  会出现一条空行，这是要消除的问题。
- `.book-title` **不加 `min-height`**：曾经用 `min-height: 2.7em` 预留两行以便跨卡片对齐，
  但单行标题时那多出来的一行就是肉眼可见的「空一行」，必须去掉。
- `.book-title` 加 `margin-bottom: -0.175em`：`line-height: 1.35` 会在文字下方留出
  `(1.35-1)/2 = 0.175em` 的半行距，用等量负外边距抵消，使「标题→数量时间」与
  「数量时间→按钮」的**视觉间距都等于 `gap: 10px`**。用 `em` 是为了在移动端字号变化时同样成立。

### 关于卡片高度：两个失败方案

高度这块走过两次弯路，记下来避免回退：

1. **固定 / 过小的 `min-height`（如 118px）会裁掉两行标题。** 两行标题的实际内容高度约 133px，
   `min-height` 小于它时，flex 会把标题压扁，第二行被 `overflow: hidden` 裁掉
   （实测 `scrollHeight=43` 但 `clientHeight=33`）。
2. **`min-height` 大于内容高度（如 142px）会在按钮下方留大片空白。** 单行标题的卡片实测
   按钮下方空白达 30px。

结论：不设 `min-height`，让内容决定高度。这样单行、两行标题都既不裁切也不留白。

- `.book-actions` 去掉 `margin-left: auto`，改为独立一行并**靠左**对齐。
- 按钮尺寸（28px / 移动端 26px）与图标大小不变。
- 删除 `≤640px` 断点中的 `.book-tag { display: none }`，手机上第二行同样显示数量与时间；
  窄屏下日期由 `YYYY-MM-DD` 切换为 `MM-DD`，避免第二行溢出。

## 五、交付物三：首页大标题改用项目名

首页 `h1` 由「我的词汇本」改为项目名「**词汇本 · 多词库学习**」，与 `README` 及浏览器标题
保持一致。学习页顶部标题仍是当前词汇本名称，不受影响。

## 六、验收标准

1. 首页导入按钮下方出现查询框，样式与整体一致。
2. 输入书名片段，只显示标题命中的卡片；输入单词或中文释义片段，显示包含该词的卡片；
   两者混合时结果取并集。
3. 过滤时计数徽标显示「匹配 M / 共 N 个词汇本」，卡片第二行显示「命中 K 词」。
4. 点击「×」或按 `Esc` 后恢复完整书架，输入框同时清空。
5. 无匹配时显示空态与「清除查询」按钮。
6. 每张卡片呈三行：标题 / 数量+时间 / 分享+删除按钮，三行之间只有统一的 `6px` 间距，
   标题与数量/时间之间**没有空行**；按钮靠左。
7. 桌面与 375px 窄屏下三行均不溢出、不重叠，同一行的卡片各行的垂直位置对齐。
8. 输入框在过滤重绘后保持聚焦，可连续输入。
9. 首页大标题显示「词汇本 · 多词库学习」。
10. 打开词汇本学习、返回、分享导出等原有流程不受影响。

## 七、验证方式

项目为零构建单文件应用、无测试框架，采用无头 Chrome 实测验证：注入示例词汇本后测量
`.book-title` / `.book-meta` / `.book-actions` 相对卡片的几何位置，确认三行间距与对齐；
并分别截图默认、命中、无结果三种状态，在桌面宽度与 375px 窄屏下逐一核对上述验收标准。
