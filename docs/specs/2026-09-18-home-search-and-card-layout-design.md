# 设计文档：首页查询输入 + 卡片三行布局

- 日期：2026-09-18
- 状态：已确认，待实现
- 作者：geek-xin

## 一、背景

词汇本首页（`index.html` 的 `#homeView`）目前只有「导入词汇本」一个操作入口，词汇本数量变多后
只能靠肉眼在卡片网格里找，缺少检索能力。

同时，`.book-card` 目前是两行结构：第一行标题，第二行把「词数 + 时间 + 分享/删除按钮」挤在
同一个 `.book-meta` flex 行里（按钮靠 `margin-left: auto` 推到最右）。信息与操作混排，卡片内
容一多就显得拥挤。

本次改动解决这两点，不涉及数据结构和存储逻辑。

## 二、范围

| 项 | 结论 |
| --- | --- |
| 查询范围 | 词汇本**标题**，或词条**单词**、**中文释义**命中 |
| 查询位置 | 首页导入按钮行与卡片网格之间 |
| 数据影响 | 无。纯前端过滤，不新增存储键、不改动已存词汇本 |
| 卡片结构 | 由两行改为三行：标题 / 数量+时间 / 按钮 |
| 移动端时间标签 | 取消原本的 `display: none`，第二行正常显示数量与时间 |

## 三、交付物一：首页查询输入

### 结构

在 `.home-actions` 与 `.book-grid` 之间新增一行 `.home-search`，包含放大镜图标、
`<input type="search">` 与一个清除「×」按钮。输入框放在 `#bookGrid` **之外**，因此
`renderHome()` 重绘网格时不会丢失输入焦点与光标位置。

`body.home-mode #homeView .home-search` 需要加入 `flex: 0 0 auto` 规则组，保证首页依旧是
「标题 / 导入 / 查询」固定、仅卡片区滚动。

### 匹配规则

大小写不敏感、去除首尾空格。一个词汇本满足下列任一条件即显示：

1. `book.title` 包含关键词；
2. `book.words` 中存在词条，其 `word` 或 `meaningCn` 包含关键词。

空查询视为不过滤，显示全部词汇本。

### 交互

| 场景 | 行为 |
| --- | --- |
| 输入 | `input` 事件实时过滤，立即重绘网格 |
| 有查询 | 显示「×」按钮，点击清空 |
| 键盘 | 输入框内按 `Esc` 清空查询 |
| 计数徽标 | 过滤时显示「匹配 M / 共 N 个词汇本」，未过滤时为「共 N 个词汇本」 |
| 卡片提示 | 命中单词的卡片在第二行追加「命中 K 词」标签 |
| 无结果 | 网格内显示空态：提示语 + 「清除查询」按钮；无词汇本时的原有空态保持不变 |

### 视觉

沿用现有玻璃拟态风格：`rgba(255, 255, 255, 0.08)` 背景、1px 半透明描边、12px 圆角，
聚焦时边框转为主题黄色 `rgba(255, 217, 102, 0.42)`，与卡片 hover 态一致。

## 四、交付物二：卡片三行布局

### 结构

| 行 | 元素 | 内容 |
| --- | --- | --- |
| 1 | `.book-title` | 标题，最多 2 行截断（不变） |
| 2 | `.book-meta` | 词数 + 创建时间（+ 命中时的「命中 K 词」标签） |
| 3 | `.book-actions` | 分享、删除按钮，右对齐 |

### 样式调整

- `.book-card` 高度 `118px → 150px`；`≤640px` 断点 `106px → 132px`。
- `.book-actions` 去掉 `margin-left: auto`，改为独立一行并右对齐。
- 按钮尺寸（28px / 移动端 26px）与图标大小不变。
- `.book-meta` 保留 `margin-top: auto`，让第二行贴住底部、第三行紧随其后。
- 删除 `≤640px` 断点中的 `.book-tag { display: none }`，手机上第二行同样显示数量与时间。

## 五、验收标准

1. 首页导入按钮下方出现查询框，样式与整体一致。
2. 输入书名片段，只显示标题命中的卡片；输入单词或中文释义片段，显示包含该词的卡片；
   两者混合时结果取并集。
3. 过滤时计数徽标显示「匹配 M / 共 N 个词汇本」，卡片第二行显示「命中 K 词」。
4. 点击「×」或按 `Esc` 后恢复完整书架，输入框同时清空。
5. 无匹配时显示空态与「清除查询」按钮。
6. 每张卡片呈三行：标题 / 数量+时间 / 分享+删除按钮；桌面与 375px 窄屏下均不溢出、不重叠。
7. 输入框在过滤重绘后保持聚焦，可连续输入。
8. 打开词汇本学习、返回、分享导出等原有流程不受影响。

## 六、验证方式

项目为零构建单文件应用、无测试框架，采用浏览器手工验证：打开 `index.html`，造出多个词汇本
（含中文释义不同的词条），逐条走查上述验收标准，并分别在桌面宽度与 375px 窄屏下确认卡片布局。
